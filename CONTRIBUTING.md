# Contributing to Awesome AI

Thank you for your interest in contributing! This is a curated list, so please ensure that additions meet the quality bar before submitting.

## Guidelines

- **Relevance**: Only add tools, extensions, skills, plugins, or resources that are directly related to AI assistants.
- **Quality**: Only suggest resources that you have personally used or that have demonstrated value to the community.
- **Description**: Each item should have a clear, concise description (one line is usually sufficient).
- **No duplication**: Check that the item is not already listed.
- **Links**: Ensure all links are working and point to the most up-to-date source.

## How to Submit

1. Fork the repository.
2. Create a new branch: `git checkout -b add-<item-name>`.
3. Add your item in alphabetical order within its section.
4. Open a Pull Request with a short description of what you are adding and why it belongs on the list.

## Code of Conduct

Be respectful and constructive. Contributions that are promotional, spam, or off-topic will be closed without merging.
