# Gemini

> A curated list of awesome tools, extensions, and resources for Google Gemini.

[Google Gemini](https://gemini.google.com/) is a multimodal AI assistant developed by Google DeepMind. It supports text, images, audio, video, and code.

## Tips & Tricks

- Use `@` mentions in Gemini Advanced to invoke specific extensions inline.
- Combine extensions (e.g., Google Search + Google Workspace) in a single prompt for richer results.
- Use Gemini in Google Docs/Sheets/Slides via the "Help me write" and "Help me organize" features.
