# Gemini Extensions

> A curated list of Gemini Extensions.

Gemini Extensions connect Gemini to Google services and third-party apps, allowing it to retrieve real-time information and take actions on your behalf.

## Contents

- [Google First-Party Extensions](#google-first-party-extensions)
- [Productivity](#productivity)
- [Developer Tools](#developer-tools)

---

## Google First-Party Extensions

Official extensions built by Google.

| Extension | Description |
|-----------|-------------|
| **Google Search** | Lets Gemini search the web for up-to-date information. |
| **Google Workspace** | Integrates with Gmail, Docs, Drive, Calendar, and Meet. |
| **Google Maps** | Provides location search, directions, and place details. |
| **YouTube** | Enables searching and summarizing YouTube video content. |
| **Google Flights** | Searches for flight information and pricing. |
| **Google Hotels** | Searches for hotel availability and pricing. |

## Productivity

Extensions that boost day-to-day productivity.

| Extension | Description |
|-----------|-------------|
| **Google Tasks** | Manage and query your task lists directly in Gemini. |
| **Google Keep** | Access and create notes in Google Keep from Gemini. |

## Developer Tools

Extensions useful for software development workflows.

| Extension | Description |
|-----------|-------------|
| **Google Cloud** | Query Cloud resources and documentation from Gemini. |
| **Firebase** | Interact with Firebase projects and documentation. |
