# Codex

> A curated list of awesome tools, resources, and workflows for OpenAI Codex.

[OpenAI Codex](https://openai.com/blog/openai-codex) is an AI system that translates natural language to code. It powers GitHub Copilot and can be accessed via the OpenAI API.

## Use Cases

- **Code Completion** — Autocomplete code snippets and entire functions.
- **Code Generation from Comments** — Write a natural language comment and let Codex generate the implementation.
- **Code Explanation** — Ask Codex to explain what a block of code does.
- **Unit Test Generation** — Generate unit tests for existing functions.
- **Shell Command Generation** — Describe what you want to do in natural language and get the shell command.
- **SQL Query Generation** — Generate SQL queries from natural language descriptions.
- **Regex Generation** — Describe the pattern you need and get the regular expression.

## Tips & Tricks

- Be specific in your prompts — include the language, framework, and expected behavior.
- Provide function signatures or type hints to guide Codex toward the right implementation.
- Use docstrings or comments above a function as the prompt for filling in the body.
- Iterate: if the first generation isn't right, refine the prompt and try again.
