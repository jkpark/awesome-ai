# Skills

> A curated list of skills that can be used across multiple AI agents.

Skills are self-contained capabilities or prompt techniques that are not tied to a specific AI platform. They can be applied to Gemini, Codex, Claude, OpenClaw, and other AI assistants.

## Prompting

Skills for crafting effective prompts.

- **Chain-of-Thought (CoT)** — Guide the model to reason step by step before giving a final answer.
- **Few-Shot Prompting** — Provide a few examples in the prompt to steer the model's output format and style.
- **Role Prompting** — Assign a persona (e.g., "You are an expert software engineer") to shape responses.
- **Self-Consistency** — Generate multiple reasoning paths and pick the most common answer to improve reliability.

## Code Generation

Skills for generating and reviewing code.

- **Test-Driven Development (TDD) Prompting** — Ask the model to write tests first, then implement code to pass them.
- **Refactoring** — Instruct the model to improve code quality without changing observable behavior.
- **Code Review** — Ask the model to review code for bugs, security issues, and style violations.
- **Documentation Generation** — Ask the model to generate inline comments, docstrings, or API docs.

## Summarization

Skills for condensing and extracting information.

- **Extractive Summarization** — Ask the model to pull key sentences directly from a source text.
- **Abstractive Summarization** — Ask the model to paraphrase and condense information in its own words.
- **Bullet-Point Summary** — Request a concise bulleted list of the main points.

## Translation

Skills for language translation and localization.

- **Direct Translation** — Translate text from one language to another while preserving meaning.
- **Localization** — Adapt content for cultural context, idioms, and regional conventions.
- **Back-Translation Validation** — Translate back to the source language to verify accuracy.

## Data Analysis

Skills for analyzing and interpreting data.

- **Data Cleaning** — Ask the model to identify and fix inconsistencies or missing values in a dataset.
- **Pattern Recognition** — Instruct the model to identify trends and anomalies in structured data.
- **SQL Generation** — Generate SQL queries from natural language descriptions.

## Writing

Skills for creating written content.

- **Tone Adjustment** — Ask the model to rewrite text in a specific tone (formal, casual, persuasive, etc.).
- **Grammar and Style Correction** — Request grammar fixes and style improvements.
- **Content Expansion** — Ask the model to elaborate on a brief outline or topic.
- **Content Condensation** — Ask the model to shorten verbose content while retaining key points.
