# Claude Code Plugins

> A curated list of Claude Code plugins.

Claude Code plugins extend the functionality of Claude Code, allowing it to interact with external tools, services, and development environments.

## Contents

- [Development Tools](#development-tools)
- [Version Control](#version-control)
- [Testing](#testing)
- [Documentation](#documentation)

---

## Development Tools

Plugins that integrate Claude Code with development environments and tools.

| Plugin | Description |
|--------|-------------|
| **VS Code Extension** | Integrates Claude Code directly into Visual Studio Code for inline suggestions and chat. |
| **JetBrains Plugin** | Brings Claude Code capabilities to IntelliJ IDEA, PyCharm, WebStorm, and other JetBrains IDEs. |
| **Neovim Plugin** | Integrates Claude Code with Neovim via a Lua plugin. |

## Version Control

Plugins that connect Claude Code to version control systems.

| Plugin | Description |
|--------|-------------|
| **GitHub Integration** | Read issues, PRs, and code from GitHub repositories directly in Claude Code. |
| **GitLab Integration** | Connect Claude Code to GitLab projects, merge requests, and CI/CD pipelines. |

## Testing

Plugins for test generation and execution.

| Plugin | Description |
|--------|-------------|
| **Test Runner** | Run tests and feed results back to Claude for automatic debugging. |
| **Coverage Analyzer** | Analyze test coverage and let Claude suggest additional test cases. |

## Documentation

Plugins for documentation generation and management.

| Plugin | Description |
|--------|-------------|
| **Docstring Generator** | Automatically generate docstrings and inline comments for your code. |
| **README Generator** | Generate or update README files based on your project structure and code. |
