## Tips & Tricks

- Use `/help` inside Claude Code to see available commands and capabilities.
- Use CLAUDE.md files in your project root to give Claude persistent context about your codebase.
- Use `@` to reference specific files or symbols in your prompts.
- Break complex tasks into smaller subtasks for more reliable results.
- Use Claude's extended thinking mode for complex reasoning tasks.
